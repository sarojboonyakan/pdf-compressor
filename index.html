วิธินำโค้ดนี้ไปเปิดเป็นเว็บส่วนตัวด้วย GitHub Pages (ฟรี 100%)

ทำตามขั้นตอนง่ายๆ เพียง 4 ขั้นตอนด้านล่าง เพื่อสร้างเว็บย่อไฟล์ PDF ไว้ใช้งานเองตลอดไป

1

สร้าง Repository ใหม่บน GitHub

เข้าไปที่ github.com/new (หากยังไม่มีบัญชีให้สมัครฟรี) แล้วตั้งชื่อ Repository เช่น pdf-compressor และเลือกสถานะเป็น Public

2

เพิ่มไฟล์ index.html

กดปุ่ม Add file > Create new file จากนั้นตั้งชื่อไฟล์ว่า index.html

คัดลอกโค้ดไฟล์ HTML นี้ทั้งหมดไปวางในช่องบรรณาธิการ แล้วกด Commit changes... ที่มุมขวาบน

3

เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings ของ Repository นั้น > เลือกเมนู Pages ที่แถบซ้ายมือ

ในหัวข้อ Build and deployment ตรงช่อง Branch ให้เปลี่ยนจาก None เป็น main (หรือ master) แล้วกด Save

4

เสร็จสิ้น! รอรับลิงก์ใช้งาน

รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์หน้าเว็บส่วนตัวของคุณ เช่น:
https://your-username.github.io/pdf-compressor/

ข้อดี: เว็บไซต์นี้ไม่ต้องใช้เซิร์ฟเวอร์แบ็กเอนด์ในการประมวลผล ดังนั้น GitHub Pages จึงสามารถโฮสต์ให้คุณใช้งานได้ฟรี 100% โดยไม่มีข้อจำกัดเรื่องโควตาไฟล์!
